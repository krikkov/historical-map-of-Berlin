# Берлин · Карта-машина времени

Интерактивная стилизованная карта Берлина, на которой можно переключать год (1850 → 2026)
и смотреть, как менялся город: какие здания ещё не построены, где проходила Стена,
как раньше назывались улицы. Чем дальше в прошлое — тем «старее» выглядит сама карта
(выцветание, сепия, зерно бумаги, штриховка, шрифт в разрядку).

## Что внутри

- **Настоящая геометрия улиц и домов** — векторные тайлы OpenStreetMap через
  [OpenFreeMap](https://openfreemap.org) (без ключей и лимитов).
- **Только нужные подписи** — названия улиц и номера домов (номера появляются с зума 17).
- **Берлинская стена 1989** — реальные данные Geoportal Berlin (dl-de/zero-2.0):
  передняя стена, стена тыла и полоса отчуждения, видны при 1961–1989 годах.
- **Западный Берлин** — полигон, собранный из линии пограничной стены (≈487 км²).
- **Переименования улиц** — подписи меняются сами: Stalinallee, Wilhelm-Pieck-Straße,
  Clara-Zetkin-Straße, Leninallee, Marx-Engels-Platz и др.
- **Исчезнувшие здания** — Городской дворец, Дворец Республики, Ангальтский вокзал,
  Лертский вокзал, Новая рейхсканцелярия, Шпортпаласт и др.
- **«Заплатки» эпох** — пустырь на Потсдамер Платц, товарная станция на месте Хауптбанхофа,
  поля на месте Марцана, Гропиусштадта, Хеллерсдорфа и BER, аэродромы Темпельхоф и Тегель.
- **Рост города** — приблизительные контуры застройки 1850/1875/1900/1920/1940/1965/1985.
- **Хроника года** — что построили, что снесли, что скоро появится; клик — перелёт к месту.

Управление: слайдер и кнопки года справа сверху, `←`/`→` (Shift — шаг 10 лет),
`пробел` — автопутешествие, удержание кнопки «👁» — сравнение с сегодняшним днём.

## Запуск

```bash
npm install
npm run dev      # локальная разработка
npm run build    # сборка → dist/index.html (один самодостаточный файл)
```

## Публикация на GitHub Pages

Сборка создаёт **один файл** `dist/index.html` со всем JS/CSS внутри, поэтому
проблем с путями на Pages нет.

Вариант 1 — вручную: скопируйте `dist/index.html` в корень ветки `gh-pages`
(или в папку `docs/` в `main`) и включите Pages в настройках репозитория.

Вариант 2 — автоматически: в репозитории уже лежит workflow
`.github/workflows/deploy.yml`. Включите в Settings → Pages источник
«GitHub Actions» — и каждый push в `main` будет публиковать карту.

## Источники данных

- OpenStreetMap contributors (ODbL) — геометрия города, тайлы OpenFreeMap.
- Geoportal Berlin / Forum für Geschichte und Gegenwart e.V. — «Verlauf der Berliner Mauer, 1989»
  (WFS `berlinermauer`), лицензия dl-de/zero-2.0.
- Исторические даты и переименования — по общедоступным источникам; контуры застройки
  и «заплатки» эпох — стилизованная реконструкция, а не кадастровая точность.
